# The Wealthy Invest - WIN

A clean static starter site for **The Wealthy Invest**.

## Positioning

**Capital strategy for investors, entrepreneurs and business owners.**

Core message:

> Capital follows clarity.

The site is designed around WIN's decision-first approach to capital, financing, business operations and evergreen learning.


## GitHub Pages

1. Upload all files and folders to the repository.
2. Open **Settings**.
3. Click **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.

GitHub will publish the site from `index.html`.
